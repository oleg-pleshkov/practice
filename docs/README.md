# Дневник разработки: Технический отчет о создании веб-ресурса проекта «КупиУмно»

В рамках выполнения практических заданий по дисциплине «Проектная деятельность» был разработан статический многостраничный веб-сайт для информационного сопровождения студенческого проекта «КупиУмно» (Московский Политех). Ниже представлен трехдневный хронологический лог разработки (DevLog) с описанием технических этапов освоения технологий HTML5 и CSS3.

## День 1: Проектирование архитектуры и создание информационного каркаса (`index.html`, `about.html`, `team.html`)
Начальным этапом работы стало изучение синтаксиса языка разметки HTML5 и создание базовой структуры сайта. Были освоены принципы декларации типа документа `<!DOCTYPE html>` и назначение обязательных тегов `<html>`, `<head>` и `<body>`. 

В первый день были спроектированы три ключевые страницы:
* **`index.html`:** Сформирована сквозная панель навигации (`<header>`), включающая семантический тег `<nav>` и список `<ul>` / `<li>` для организации переходов. Основная область отведена под секцию `.hero` с аннотацией платформы агрегации цен.
* **`about.html`:** Выполнен перенос аналитических данных из Пояснительной записки. Описание проблематики рынка e-commerce и решений платформы «КупиУмно» оформлено с помощью маркированных списков `<ul>`. Важные термины выделены тегом логического акцента `<strong>`.
* **`team.html`:** Отражена структура проектной группы (8 человек). Изучено различие между блочными и строчными элементами. Для реализации будущей сетки создан родительский контейнер `<div class="team-grid">` и 8 дочерних блоков `<div class="team-card">` с заголовками `<h3>` для ФИО и абзацами `<p>` для фиксации персонального вклада.

## День 2: Семантическая разметка хроники, внешних связей и графики (`journal.html`, `resources.html`)
Второй день был посвящен изучению семантических стандартов HTML5, интеграции внешних ссылок и подготовке разметки под медиа-контент.

* **`journal.html`:** Для фиксации этапов практики (сбор материалов, презентация, пояснительная записка) вместо избыточных `<div>` применен семантический тег `<article>`. Это необходимо для повышения доступности интерфейса (Accessibility) и улучшения SEO. В этот же день была подготовлена разметка для интеграции ленточной диаграммы Ганта, отражающей хронологию выполнения работ группой 253-331.
* **`resources.html`:** Создана страница нормативно-правовой базы и внешних источников (блоги Ozon Tech, Яндекс Исследования, законы РФ № 152-ФЗ и № 149-ФЗ). Отработаны навыки использования тега `<a>`. Для всех внешних ссылок добавлен атрибут `target="_blank"`, открывающий сторонние ресурсы в новых вкладках и сохраняющий сессию пользователя на сайте.
* **Интеграция графики:** Были изучены правила внедрения медиа-контента через тег `<img>`. В качестве временных плейсхолдеров на страницах проекта использован файл `img/justimg.png`, имитирующий итоговое расположение проектных иллюстраций (карта стейкхолдеров, профиль целевой аудитории User Persona и диаграмма Ганта). Для каждого элемента прописан обязательный атрибут `alt` и подготовлены блоки для подрисуночных надписей по ГОСТу.

## День 3: Визуальное оформление и сборка каскадных таблиц стилей (`style.css`)
Заключительный этап разработки был полностью посвящен стилизации интерфейса. Весь CSS-код был вынесен в отдельный изолированный файл `style.css` и подключен ко всем пяти HTML-страницам через элемент `<link>` в секции `<head>`.

В рамках реализации визуальной концепции были выполнены следующие технические задачи:
1. **Глобальный сброс стилей:** Использован универсальный селектор `*` для обнуления дефолтных браузерных отступов (`margin: 0; padding: 0; box-sizing: border-box;`) с целью обеспечения кроссбраузерной стабильности макета.
2. **Цветовое кодирование:** Внедрена официальная цветовая гамма Московского Политеха с акцентным красным цветом (`#ff0033`) для элементов навигации, заголовков и кнопок.
3. **Верстка макета на Flexbox:** Свойства `display: flex;` были применены для трансформации вертикальных списков меню в горизонтальные панели, а также для автоматического распределения элементов сетки `.team-grid` с вычислением пропорциональной ширины карточек (`width: calc(25% - 1.125rem);`).
4. **Оформление медиа-контента:** Для интегрированных схем и диаграмм настроен адаптивный класс `.project-img` со свойством `max-width: 100%`, предотвращающий выход графики за пределы родительского контейнера, и заданы строгие стили для центрирования подрисуночных подписей.
5. **Интерактивность:** Реализованы ховер-эффекты с помощью псевдокласса `:hover` и свойства плавного перехода `transition` для улучшения пользовательского опыта (UX) при взаимодействии с меню и внешними ссылками.

**Итог:** В результате трехдневного интенсивного цикла разработки спроектирован функционирующий многостраничный веб-сайт, решающий задачи информационного отчета по практике и полностью соответствующий современным базовым стандартам веб-верстки.
